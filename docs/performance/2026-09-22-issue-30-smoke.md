# Issue 30 projection and ASOF smoke comparison — 2026-09-22

This is a same-host diagnostic, not a reference baseline or an end-to-end throughput claim.
Both versions used Rust 1.96.0 (`ac68faa20`), release builds, the smoke profile,
Intel Core i5-14400F, x86_64 WSL2 Linux 6.6.87.2, and the same ext4 filesystem.
The WSL guest exposed 16 logical CPUs and approximately 7.6 GiB RAM. Cargo builds were
limited to two jobs; builds and benchmark processes ran sequentially. Host scheduling,
CPU frequency and filesystem latency were not controlled. Criterion used 10 samples,
100 ms warmup and 200 ms measurement; these short runs contain outliers.

Before is `c0b584c`, with only the column-projection benchmark harness added. Its
identity/subset/Decimal/empty cases use the old `ProjectDefinition`; after uses
`SelectDefinition` with equivalent named column expressions. Fixture, Arrow oracle,
row counts and timed boundaries are identical. The other before targets are unchanged.
After is the issue 30 implementation accompanying this report. No previous platform's
performance numbers are used as a baseline.

## Complete ASOF Claim latency

Each iteration inserts one Claim and retracts it, restoring the initial relation.
Timing includes all committed turns, synchronous Store commits and AfterCommit;
fixture construction, seeding and output validation are outside timing. Values are
Criterion lower / point / upper estimates in milliseconds for the two-Claim pair.

| Case | Before (ms) | After (ms) | Point change |
| --- | --- | --- | --- |
| global_partition_lookup | 2.077 / 2.171 / 2.273 | 2.035 / 2.141 / 2.270 | -1.4% |

| right_tail_small_rematch | 6.110 / 6.518 / 6.737 | 4.031 / 4.392 / 4.904 | -32.6% |

The two right-rematch cases improve by approximately one third in this run. Lookup
cases are near their previous values; residual fallback is 6.1% slower in this sample.
This does not establish a universal latency improvement or a persistent regression in
that case. Committed-turn and resource evidence below are independent of timing noise.
